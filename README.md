# 海外AIニュース速報｜AI外電

海外のAI関連企業・研究組織が公式に配信するRSS/Atomフィードを収集し、日本語の短い日刊ダイジェストとして公開する自動運用サイトです。

> 試験運用中：本サイトの記事は、公式フィードを基に機械的な収集・自動翻訳・定型編集を行う予定です。翻訳や要約に誤りが含まれる可能性があるため、重要な情報は必ずリンク先の公式発表をご確認ください。

## MVPの範囲

- 公式RSS/Atomフィードのみを取得
- 英語タイトルとフィード概要をローカル翻訳モデルで日本語化
- 日付別のニュースダイジェストを静的生成
- SEOを意識したメタ情報・構造化データ・サイトマップを生成
- GitHub Actionsで毎日更新
- Cloudflare Pagesへ自動デプロイ
- 当面はCloudflareの`*.pages.dev` URLで運用

Blueskyへの自動告知は次のフェーズで実装します。

実装要件は [`docs/IMPLEMENTATION_SPEC.md`](docs/IMPLEMENTATION_SPEC.md)、Codex向けの作業指示は [`AGENTS.md`](AGENTS.md) を参照してください。
